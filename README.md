# 🌻 WordBloom

**Grow your vocabulary, one word at a time.**

WordBloom is a Flutter-based English vocabulary learning application designed to make learning new words simple, enjoyable, and consistent.

The idea behind WordBloom is simple: learning a language shouldn't feel like another chore. Small daily steps can lead to meaningful progress.

## 🌱 About the Project

WordBloom is an independent mobile development project combining language learning, thoughtful UI design, and interactive learning experiences.

The app is designed around a growing vocabulary collection, personalized progress, and a virtual garden that reflects your learning journey.

**Current status:** In active development 🚧

## ✨ Features

### Currently Implemented

- 📖 **Daily Word:** Discover a new vocabulary word every day.
- 🔎 **Vocabulary Explorer:** Search and explore English vocabulary.
- 🎯 **CEFR Levels:** Browse words from A1 to C2.
- 💾 **Saved Words:** Bookmark words and keep them saved between sessions.
- 🌱 **Learning Garden:** A dedicated space for vocabulary progress.
- 🍃 **Leaf Points:** A reward system connected to the learning experience.
- 🎨 **Custom UI:** A soft, pastel-inspired interface with reusable components.
- 📚 **Offline Vocabulary:** An initial curated collection of 1000 English words.

## 🛠️ Built With

- **Flutter & Dart** — Cross-platform mobile development
- **JSON** — Structured vocabulary data
- **SharedPreferences** — Local data persistence
- **Material Design** — UI components and navigation
- **Git & GitHub** — Version control

## 💻 Getting Started

To run WordBloom locally:

**1. Clone the repository**

```bash
git clone https://github.com/Helloitsalia/WordBloom.git
```

**2. Navigate to the project**

```bash
cd WordBloom
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

Make sure Flutter is installed and an emulator or physical device is available.
